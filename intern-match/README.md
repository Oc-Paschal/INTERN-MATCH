# InternMatch NG 🇳🇬

InternMatch NG is an AI-powered internship discovery platform tailored specifically for the Nigerian market. It bridges the gap between tertiary institution students and top-tier employers through a data-driven matching system.

## 🚀 Key Features

*   **AI Smart Matching:** A personalized algorithm that calculates match scores based on student skills, career goals, and company requirements.
*   **Geospatial Discovery:** An interactive Map View allowing students to visualize internship opportunities in major hubs like Lagos, Abuja, and Port Harcourt.
*   **Professional Profiles:** Comprehensive student profiles featuring skill tagging, CV uploads, and GitHub integration.
*   **Internship Tracker:** A centralized dashboard to manage applications and interview stages.
*   **Verified Employers:** A curated list of verified companies to ensure a safe and high-quality experience for interns.

## 🛠️ Tech Stack

### Frontend
*   **Framework:** React 18
*   **Build Tool:** Vite
*   **Styling:** Tailwind CSS
*   **Animations:** Custom `requestAnimationFrame` hooks for high-performance UI transitions.
*   **Icons/Graphics:** Custom SVG-based geospatial visualizations.

### Backend (In Progress)
*   **Proposed Stack:** Node.js (Express), PostgreSQL (via Prisma ORM).
*   **Authentication:** JWT-based secure auth system.

## 📦 Getting Started

1.  **Clone the repository:**
    ```bash
    git clone [repository-url]
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```
